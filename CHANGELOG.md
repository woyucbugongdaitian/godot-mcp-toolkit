# Changelog

## 0.4.0

- Added structured runtime logs, performance snapshots, rigid-body contact inspection, Audio Bus effect chains, meter/spectrum analysis, NavigationRegion3D baking, import inspection, export-preset discovery, and safe CLI exports.
- Added Script Editor buffer edits, AnimationTree transition/BlendSpace workflows, Skeleton3D/Skin authoring, Theme fonts/icons/type variations, generic resource editing, and TileSet alternatives/terrain/proxy authoring.
- Added 2D/3D runtime point and primitive-shape overlap queries plus navigation path queries.
- Added deep authoring tools for AnimationTree state machines, Bezier curves, timeline settings, Theme subresources, generic resource assignment, TileSet atlas/Terrain work, and editable ArrayMesh surfaces.

- Renamed the public project to **Godot MCP Toolkit**.
- Added runtime property watches, event polling, rolling frame metrics, and high-level pointer input injection.
- Added semantic 2D camera/light, UI component, and stylized rendering editor tools.
- Added editor/runtime binding coverage for the newly exposed tool groups.
- Consolidated public documentation and added GitHub collaboration files.
