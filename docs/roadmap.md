# Roadmap

The toolkit prioritizes stable, verifiable semantic operations over brittle UI automation. The next major areas are:

- Script Editor write-side selection, breakpoint management, completion state, and richer debugger snapshots.
- Skeletons, skinning, mesh editing, state-machine graph authoring, curve editing, and advanced animation workflows.
- Navigation mesh baking, path-query events, shape physics queries, contact information, and debug visualization.
- Audio Bus effect-chain editing, spectrum analysis helpers, and meter snapshots.
- Import and export preset management, platform export execution, and preflight validation.
- Advanced TileMap terrain/atlas workflows, Theme resource sub-editing, and broader editor workspace layout controls.

Feature work is added through tool groups, tests, and versioned documentation to avoid exposing an unmanageable flat tool list.
